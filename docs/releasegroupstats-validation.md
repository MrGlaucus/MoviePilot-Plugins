## 设计调整

- 对照官方 V2/V3 `PageRender.vue`，原生详情页不支持表单模型绑定。筛选关键词放在配置页，保存生效。
- 实际 Vue/Vuetify 渲染发现 `VDataTable` 的默认插槽被宿主覆盖，表头/数据行无法显示。改为显式 `VTable`，排序与每页 10 行分页通过实例内 `/ranking_view` 接口完成。
- 发布流程仅为新增版本生成发布计划，严格按各索引对应源码目录打包；同 Tag 不同代码会拒绝打包。已有 Release 和 Tag 不自动删除覆盖。

- 回归测试覆盖核心文件系统行为、宿主边界替身、真实 Cron、版本一致性和发布计划冲突。

## 安装后验收建议

1. 配置一组可读目录、一个不存在的目录，确认部分完成警告与文件计数。
2. 保存后扫描一次，检查开关复位；扫描过程中取消、禁用或重载，确认旧任务不覆盖结果。
3. 点击详情页排名表头、上下页和刷新状态；查看空状态、未识别样例与仪表板。
4. 检查定时服务、远程命令和 V3 多实例各自的数据目录与控制入口。
