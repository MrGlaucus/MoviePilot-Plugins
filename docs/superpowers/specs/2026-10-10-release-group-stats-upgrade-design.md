# 发布组统计修复、UI 优化与 V3 支持设计

## 目标与范围

改进现有 V2 插件，并增加独立 V3 插件。继续以 MoviePilot 容器内挂载目录为数据源；按视频文件统计数量与逻辑容量，不把电视剧的一集等同于一部作品，也不把逻辑容量标成磁盘实际占用。保留旧配置字段和 `stats_data.json` 的读取兼容性。

## 已发现的问题

- 组名及别名无边界子串匹配，短名称可能匹配片名；`VCB-Stuido` 拼写错误。
- 路径只支持分号；重复目录及父子目录会重复统计。
- 扫描先收集所有文件，再逐组保存全部路径，大型媒体库内存及结果文件持续膨胀。
- `_is_scanning` 的检查和赋值没有互斥；API 可以同时创建多个线程。
- `stop_service()` 仅将标志改为 False，旧线程仍继续扫描、写结果。
- 60 秒限制会无反馈地拒绝手动任务；失败尝试也消耗限制。
- 远程命令声明存在，但没有对应的 PluginAction 事件处理。
- 定时服务声明没有使用官方示例的 CronTrigger 对象。
- 配置页没有“立即扫描一次”；详情页没有可用的扫描入口或任务状态。
- JSON 直接覆盖写入；无效目录被跳过后，可能把有效历史结果覆盖为零。
- 没有 V3 索引和实现；发布工作流只处理 V1/V2，且优先选择 V2 目录。

## 方案选择

1. 推荐：保留原生 Vuetify JSON 页面，分离扫描核心与 UI 组装，V2/V3 各自包含完整运行文件。无需引入前端构建或额外依赖，适合本插件。
2. Vue 联邦页面：交互更自由，但新增构建、静态资源、宿主兼容维护成本，本轮不采用。
3. 仅修补 V2 并依赖 V3 兼容层：改动较少，但不能落实 V3 SDK 和独立发布，本轮不采用。

## 扫描与识别

- 路径支持换行及旧分号分隔，规范化并合并父子目录，按规范路径去重；不默认跟随目录符号链接，避免递归环。硬链接的不同路径仍按不同媒体文件计数。
- 扩展名忽略大小写，支持换行、逗号及分号；留空使用原默认集合。
- 预编译识别规则，使用字母数字边界，优先识别文件名末尾发布组；必要时回退父目录名。未知文件仍归入“其它”，不自动猜测成已知发布组。
- 保留现有站点/发布组映射，并修正明显错误；增加可选自定义规则，逐行“分类名|正则”，优先于内置规则，错误规则在配置反馈和日志中明确展示。
- 以迭代方式累计数量和容量，每组只保留有限示例路径，避免保存整库清单。
- 显示遍历文件数、匹配视频数、错误数量和执行状态。目录全部不可用、取消或致命异常时保留上次成功快照；部分读取失败允许保存结果，但明确标记统计不完整。

## 生命周期、存储与接口

- 统一手动、定时、远程命令入口，用实例锁保证同一实例只有一个任务；明确返回已运行、未配置、已停用等结果。
- 增加取消信号，停止或重载等待旧任务退出；旧任务不允许覆盖新结果。移除固定 60 秒限制。
- 增加“立即扫描一次”配置，保存后自动复位；远程命令保留 `/release_group_scan`。
- 定时服务校验 Cron，使用宿主时区；非法表达式不使插件加载失败。
- 保留 `/start_scan`，增加状态读取和取消接口，声明认证；V3 JSON 返回包含 success、message、data。
- 在插件数据目录原子替换 JSON；写入成功后再替换内存快照。旧结果读取时兼容、校验字段，不丢弃已有有效数据。
- V3 使用 `app.sdk.plugin`、`app.sdk.events`、`app.sdk.logging` 等公开入口，插件实例身份动态获取。

## UI 布局

- 配置页分为“扫描设置”和“识别规则”：启用、立即扫描一次、目录、Cron、扩展名、自定义规则，提供容器路径与文件统计口径说明。
- 详情页顶栏展示任务状态和最近成功时间，提供扫描、取消和刷新操作。
- 四张响应式概览卡：视频文件数、逻辑总容量、已识别分类数、识别率。
- 发布组排名表支持搜索、排序和分页，展示数量、数量占比、容量、容量占比，配合占比条。
- 展示有限的未识别文件示例，帮助补充规则；空数据、正在扫描、失败及部分完成具有不同提示。
- 仪表板保留 `stats` key，展示总量与 Top 5，带更新时间与任务状态，并保留空状态。

## 版本与发布

- V2 更新到 1.1.0，V3 首版为 2.0.0，使用 `plugins.v3/releasegroupstats/` 和 `package.v3.json`，最低宿主版本 `>=3.0.0`。
- V1 源码本轮保留，避免未经真实 V1 宿主验证的迁移；V2 索引声明不向 V3 回退，V3 使用专用实现。
- 发布工作流增加 V3 索引触发，严格按索引映射目录；同一插件 ID 和版本出现不同代实现时明确检查，避免静默打错包。
- 不自动推送、创建 Release 或修改已发布 Tag。

## 验证与验收

- 先建立回归测试：发布组误识别、父目录回退、重复路径、大小写扩展名、空目录与不可用目录、读取失败、任务竞争、取消与重载、原子保存、旧结果恢复、非法 Cron。
- 使用生产模块命名空间测试 V2/V3 入口；宿主不可用时使用明确隔离的最小宿主替身，报告其验证边界。
- 验证配置页、详情页和仪表板组件结构、API 返回和元数据版本一致性；执行 Python 编译与 git diff --check。
- 页面真实渲染、宿主服务注册和热重载仍需要真实 MoviePilot V2/V3 环境验收，本地替身测试不宣称覆盖这些场景。
