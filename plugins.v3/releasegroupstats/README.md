# 发布组统计

扫描 MoviePilot 可访问的媒体目录，按发布组或站点分类统计视频文件数量和逻辑容量。

## 使用

1. 启用插件，填写**容器内**媒体路径，每行一个；旧的分号分隔配置仍可使用。
2. 选择“保存后扫描一次”，或保存后进入详情页点击“开始扫描”。
3. 可填写五段 Cron（如 `0 2 * * *`），按 MoviePilot 配置的时区执行；留空不注册定时任务。
4. 详情页可取消扫描、刷新进度、点击排名表头排序和翻页；仪表板 `stats` 每 10 秒刷新。
5. 排名筛选关键词在插件配置页设置，保存后生效。官方原生详情渲染器没有输入框模型绑定，因此本插件不提供无效的详情页搜索框。

## 统计口径

- 一份视频文件算一条，电视剧每集分别计数；不是作品数，也不是磁盘实际占用。
- 重复路径及父子目录自动合并；不同路径的硬链接分别计数。
- 不跟随目录符号链接，也不统计文件符号链接，避免循环和链接重复计数。
- 默认扩展名：mkv、mp4、avi、iso、ts、flv、wmv、mov、m4v、webm。自定义扩展名**替换**默认集合，支持换行、逗号、分号。
- 先检查自定义规则，再识别文件名中的发布组标签；优先末尾标签，最后尝试直接父目录名。内置映射仍以旧版站点/分类为单位，例如 FRDS 归入“朋友”，多个动漫组归入 anime。
- 无法识别的文件归为“其它”；每组最多保存 10 个样例，不再保存整个媒体库的路径清单。

自定义规则每行 `分类名|正则表达式`，按配置顺序匹配，优先于内置规则；`#` 开头的行是注释：

```text
我的组|(?<![A-Za-z0-9])MYGROUP(?![A-Za-z0-9])
朋友|FRDS
```

## 可靠性与升级

- 同一实例只能执行一个扫描。取消为协作式取消；网络挂载卡住时，需等待文件系统调用返回，不能强制杀死 Python 线程。
- 取消、全部目录不可读、扫描异常、保存失败均保留上次成功结果；部分读取失败会明确标记“统计不完整”。可读空目录可得到零文件结果。
- 结果原子保存到插件数据目录 `stats_data.json`，兼容读取旧版结果；不会修改媒体文件。
- V2 版本为 1.1.0；V3 有独立的 2.0.0 实现和市场索引，使用 V3 SDK。保留相同插件 ID、配置字段及数据文件名；迁移主程序时需要保留插件配置与数据目录。

## 远程命令与 API

远程命令：`/release_group_scan`。多个启用实例收到未指定实例的命令时，各自执行扫描；带 `plugin_id` 的事件仅由目标实例响应。

以下接口位于 `/api/v1/plugin/<实例ID>/`，使用宿主 bearer 鉴权，返回 `success`、`message`、`data` 三字段；data 是扫描状态：

| 接口 | 方法 | 用途 |
| --- | --- | --- |
| `start_scan` | POST | 启动扫描 |
| `cancel_scan` | POST | 请求取消 |
| `status` | GET | 读取执行状态、进度、警告及最近成功时间 |
| `ranking_view` | POST | JSON：`{"sort":"count","descending":true,"page":1}`；sort 可为 name/count/bytes |

详情页需点击“刷新状态”读取后台最新进度；API 控制按钮和翻页完成后，宿主会自动重新加载详情页。排序和页码为当前插件实例的临时状态。
